| Bestand | Gebruik | Aanbevolen formaat |
|---|---|---|
| `portret.jpg` | Foto van jezelf (sectie "Over mij") | 1040x1240 px, staand |
| `case-1.jpg` | Screenshot/mockup van project 1 | 1600x1200 px (4:3) |
| `case-2.jpg` | Screenshot/mockup van project 2 | 1600x1200 px (4:3) |
| `case-3.jpg` | Screenshot/mockup van project 3 | 1600x1200 px (4:3) |
